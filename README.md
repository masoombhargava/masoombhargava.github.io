# Masoom Bhargava — personal academic website

A fast, static website. No build tools, no frameworks, no terminal needed.
Just HTML, CSS, and JavaScript.

## Files

```
(this folder)
├── index.html                     ← the page (all your content lives here)
├── style.css                      ← all the styling
├── script.js                      ← navigation + the animated background
├── assets/
│   └── Masoom_Bhargava_CV.pdf     ← your CV (the "Download CV" buttons link here)
└── README.md                      ← this file
```

## Run it on your own computer (no software to install)

1. Keep all the files together in one folder, exactly as above.
2. Double-click `index.html`. It opens in your web browser. That's it.

If double-clicking opens the code instead of the page, right-click `index.html`
→ **Open with** → your browser (Chrome, Edge, Safari, or Firefox).

## Change your photo (optional)

The site currently shows a small "MB" monogram instead of a photo, so it works
even with no image file. To use a real photo later:

1. Put a square photo in the `assets/` folder named `profile.jpg`.
2. Ask for the small snippet to swap the monogram for the photo — it's a
   two-line change in `index.html`.

## Update your CV later

Replace `assets/Masoom_Bhargava_CV.pdf` with your newer file, keeping the **exact
same name**. Every "Download CV" button will then serve the new version
automatically.

## Edit your text

Open `index.html` in any plain-text editor (even Notepad or TextEdit). Each
section is clearly marked with a comment like `<!-- ---------- ABOUT ---------- -->`.
Change the words between the tags; leave the tags themselves alone.
